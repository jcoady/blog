Where Part 1 left off

Part 1 showed that the rotor anchor \(\zeta=\kappa+i\rho\) is algebraically the Riemann–Silberstein vector \(\mathbf E+i\mathbf B\), and built an exact U(1) lattice out of Cayley phases \(U=(1-ia)/(1+ia)\). It listed what was missing from the gauge-theory side. This post closes the first two gaps on that list, comparing against the standard abelian gauge theory of the lecture notes (local phase \(\psi\to e^{ie\phi}\psi\), \(D_\mu=\partial_\mu+ieA_\mu\), \(F_{\mu\nu}=-\tfrac ie[D_\mu,D_\nu]\)):

  1. Calculation 11. Does the lecture’s central identity \(F_{\mu\nu}=-\tfrac ie[D_\mu,D_\nu]\) hold exactly on the Cayley lattice? Yes, in a precise form, over \(\mathbb Q\) and \(\mathbb F_p\).
  2. Calculation 12. What does a charge \(k\neq1\) field see? The map \(a\mapsto\tan(k\arctan a)\), which is the Chebyshev/spread-polynomial structure, and over \(\mathbb F_p\) it makes the theory a \(\mathbb Z_{p+1}\) gauge theory.

A third section records what is not established about tripods and the Wilson potential, so that it is not mistaken for a result.

Everything labelled “exact” below was run in exact arithmetic (Fraction over \(\mathbb Q\), modular arithmetic over \(\mathbb F_7,\mathbb F_{11}\), and exhaustively over \(\mathbb F_p\) for \(p=3,7,11,19,23\) where stated). The script is at the end.

Conventions, fixed once

The sign conventions were left loose in Part 1, so here they are pinned down.

  • Sites \(x\) on a periodic lattice, links \(U_\mu(x)\in K=F[i]\) of norm one, \(U_\mu(x)=\dfrac{1-ia_\mu(x)}{1+ia_\mu(x)}\), with \(a=\infty\mapsto U=-1\).
  • Covariant difference: \(\mathcal D_\mu\psi(x)\equiv U_\mu(x)\,\psi(x+\hat\mu)-\psi(x)\).
  • Gauge transformation: \(\psi(x)\mapsto g(x)\psi(x)\), \(\;U_\mu(x)\mapsto g(x)\,U_\mu(x)\,g(x+\hat\mu)^{-1}\), with \(g(x)\) of norm one.
  • Plaquette: \(U_P(x)\equiv U_\mu(x)\,U_\nu(x+\hat\mu)\,U_\mu(x+\hat\nu)^{-1}U_\nu(x)^{-1}\).

Sign of the link. With this \(\mathcal D_\mu\), expanding \(U_\mu(x)\psi(x+\hat\mu)-\psi(x)\) for a smooth field gives \(\varepsilon(\partial_\mu+ie A_\mu)\psi\) exactly when \(U_\mu(x)\approx e^{+ie\varepsilon A_\mu}\). So the link is \(\exp(+ie\int A)\), the plaquette is \(U_P=e^{+ie\Phi}\) (consistent with Part 1), and \(a_P=-\tan(e\Phi/2)\). Under \(A\to A-\partial\phi\) and \(\psi\to e^{ie\phi}\psi\) the lattice rule \(U\to gUg^{-1}\) reproduces \(A\to A-\partial\phi\) exactly, because \(\int\partial\phi=\phi(\text{end})-\phi(\text{start})\). Calculation 11(e) confirms the sign numerically.

Calculation 11: the lattice commutator

The identity

Apply \(\mathcal D_\mu\) to \(\mathcal D_\nu\psi\):

\[ \mathcal D_\mu\mathcal D_\nu\psi(x)=U_\mu(x)U_\nu(x{+}\hat\mu)\,\psi(x{+}\hat\mu{+}\hat\nu)\;-\;U_\mu(x)\psi(x{+}\hat\mu)\;-\;U_\nu(x)\psi(x{+}\hat\nu)\;+\;\psi(x). \]

The three lower terms are symmetric under \(\mu\leftrightarrow\nu\), so they cancel in the commutator, leaving

\[ [\mathcal D_\mu,\mathcal D_\nu]\psi(x)=\bigl[U_\mu(x)U_\nu(x{+}\hat\mu)-U_\nu(x)U_\mu(x{+}\hat\nu)\bigr]\psi(x{+}\hat\mu{+}\hat\nu). \]

Pull out \(W\equiv U_\nu(x)U_\mu(x{+}\hat\nu)\), the transporter that carries a value at \(x+\hat\mu+\hat\nu\) back to \(x\) along the \(\nu\)-first path:

\[ \boxed{\;[\mathcal D_\mu,\mathcal D_\nu]\psi(x)=\bigl(U_P(x)-1\bigr)\,\mathcal T_{\mu\nu}\psi(x),\qquad \mathcal T_{\mu\nu}\psi(x)\equiv U_\nu(x)U_\mu(x{+}\hat\nu)\,\psi(x{+}\hat\mu{+}\hat\nu).\;} \]

This is exact, for any links and any \(\psi\). It is not \((U_P-1)\psi(x)\): the factor multiplying \(U_P-1\) is \(\psi\) parallel-transported from the far corner of the plaquette, which differs from \(\psi(x)\) at relative order \(\varepsilon\). The two agree only in the continuum limit. \(\mathcal T_{\mu\nu}\psi\) itself transforms like \(g(x)\psi\), so both sides are gauge-covariant. This is the lattice form of the lecture’s step “the derivative terms cancel and only \(ieF_{\mu\nu}\psi\) survives.”

The Cayley form of the field strength

Because \(U(1+ia)=1-ia\),

\[ U_P-1=\frac{-2i\,a_P}{1+i\,a_P},\qquad \frac{U_P-1}{U_P+1}=-i\,a_P . \]

Let \(\mathcal S_{\mu\nu}\psi(x)\equiv\bigl[U_\mu(x)U_\nu(x{+}\hat\mu)+U_\nu(x)U_\mu(x{+}\hat\nu)\bigr]\psi(x{+}\hat\mu{+}\hat\nu)=(U_P+1)\mathcal T_{\mu\nu}\psi\), the sum over the two corner paths. Then

\[ a_P(x)=i\,\frac{[\mathcal D_\mu,\mathcal D_\nu]\psi(x)}{\mathcal S_{\mu\nu}\psi(x)}\qquad(\psi(x{+}\hat\mu{+}\hat\nu)\neq0). \]

So the Cayley plaquette parameter is a ratio of two path sums, difference over sum, with no exponential and no logarithm. When \(U_P=-1\) (\(a_P=\infty\)), \(\mathcal S\psi=0\).

(d) The same identity for non-abelian caps

Replace the links by \(\mathrm{SL}(2,\mathbb Q)\) Cayley caps \(\mathrm{ca}(A)=(I+A)(I-A)^{-1}\) and \(\psi\) by \(\mathbb Q^2\)-valued fields, with \(U_P=U_\mu U_\nu' U_\mu'^{-1}U_\nu^{-1}\) now a matrix. The identity \([\mathcal D_\mu,\mathcal D_\nu]\psi=(U_P-1)\mathcal T\psi\) holds verbatim, 486/486, while \(U_\mu U_\nu'\neq U_\nu U_\mu'\) on every plaquette. So the lattice commutator does not need the abelian cancellation of \(A_\mu A_\nu\) terms that the lecture discusses; what changes is that \(U_P\) stops being a product of commuting phases, so \(a_P\) is no longer an additive function of the link parameters and \(U_P\) is only gauge-covariant, not invariant. That is the point where the Yang–Mills theory starts.

What this does and does not give

  • Gives: the lecture’s key identity, exactly, on the Cayley lattice over \(\mathbb Q\) and \(\mathbb F_p\), with the correct transporter factor; the Cayley field strength as a difference-over-sum of path transports; gauge covariance of every piece.
  • Does not give: a statement that \([\mathcal D,\mathcal D]\psi=(U_P-1)\psi\) exactly. That form only holds as \(\varepsilon\to0\).
  • Still abelian-specific: \(U_P\) is gauge invariant, which the non-abelian version loses.

Calculation 12: charge as a Cayley map

The map

A charge-\(k\) field transforms as \(\psi\mapsto g^k\psi\) and sees the links \(U^k\). In Cayley variables

\[ U=\frac{1-ia}{1+ia}=e^{-2i\arctan a}\;\Longrightarrow\;U^k=\frac{1-i\,c_k(a)}{1+i\,c_k(a)},\qquad c_k(a)=\tan\bigl(k\arctan a\bigr)=\frac{\operatorname{Im}(1+ia)^k}{\operatorname{Re}(1+ia)^k}. \]

This is \(k\)-fold tangent addition, \(c_k(a)=a\oplus\cdots\oplus a\) with \(a\oplus b=(a+b)/(1-ab)\). It is not \(ka\):

\[ c_2(a)=\frac{2a}{1-a^2},\qquad c_3(a)=\frac{3a-a^3}{1-3a^2},\qquad c_k(a)\approx ka\ \text{for small }a . \]

So charge scales the potential linearly only in the weak-field limit, where \(a\approx-\tfrac12 e\varepsilon A\).

Chebyshev and spread polynomials

Writing \(c=\mathrm{Re}\,U=\frac{1-a^2}{1+a^2}\), one has exactly \(\mathrm{Re}\,U^k=T_k(c)\), the Chebyshev polynomial. In Wildberger’s language, with \(s\equiv a^2/(1+a^2)\) the spread of the phase, the spread seen by charge \(k\) is \(S_k(s)=\tfrac12\bigl(1-T_k(1-2s)\bigr)\), the \(k\)-th spread polynomial; for example \(S_2(s)=4s(1-s)\) and \(S_3(s)=s(3-4s)^2\). Over \(\mathbb F_p\): a \(\mathbb Z_{p+1}\) gauge theory

For \(p\equiv3\pmod4\) the norm map \(\mathbb F_{p^2}^\times\to\mathbb F_p^\times\) is onto, so its kernel, the norm-one phases, has order \((p^2-1)/(p-1)=p+1\). It is a subgroup of the multiplicative group of a finite field, hence cyclic. The Cayley parameters \(\mathbb P^1(\mathbb F_p)\) with \(\oplus\) are that group. So abelian gauge theory over \(\mathbb F_p\) is a \(\mathbb Z_N\) gauge theory with \(N=p+1\), and a charge is an integer mod \(N\). What periodicity does and does not say

If \(U_P\) is a genuine \(\mathbb F_p\)-rational phase then \(U_P^{p+1}=1\), so a charge \(p+1\) field decouples from the connection. In spread-polynomial language \(S_{p+1}(s)=0\), for those \(s\) that are spreads \(s=a^2/(1+a^2)\) of an \(\mathbb F_p\)-rational phase (equivalently \(s=1\) or \(s/(1-s)\) a nonzero square). It is not true for every \(s\in\mathbb F_p\). Writing \(1-2s=(z+z^{-1})/2\): if \(z^{p+1}=1\) the phase is rational and \(S_{p+1}(s)=0\); if instead \(z\in\mathbb F_p^\times\) then \(z^{p+1}=z^2\) and \(S_{p+1}(s)=S_2(s)\neq0\) in general. For \(p=7\), \(S_8(s)\) is \(0\) at \(s=0,1,3,4,5\) and equals \(6=S_2(s)\) at \(s=2,6\), exactly the two values for which \(s/(1-s)\) is a nonsquare.

The finite-field theory is a \(\mathbb Z_N\) theory only up to a choice

The group structure, Stokes, Bianchi, gauge covariance and the identities above are canonical over \(\mathbb F_p\). Turning \(\mathbb P^1(\mathbb F_p)\) into angles \(2\pi m/N\), which is what the table above uses, requires choosing a generator, i.e. a discrete logarithm. After that choice \(\cos(2\pi m/N)\) is an ordinary real number with no algebraic relation to the \(\mathbb F_p\) arithmetic. Any statement about Boltzmann weights, phases or a continuum limit for the finite-field theory is a statement about that real model, which the finite-field structure hosts but does not determine.

Tripods and the Wilson potential: what is and is not established

Part 1 and the companion papers define the solid spread of three rays \(v_1,v_2,v_3\) in a space with a nondegenerate form \(B\) as \(\mathcal S=\det G_3/(Q(v_1)Q(v_2)Q(v_3))\). A natural question is whether the Wilson plaquette potential \(W_1=1-\mathrm{Re}\,U_P\) is “twice the tripod solid spread.” What can be said:

True, but a relabelling. Define \(s_P\equiv a_P^2/(1+a_P^2)\). Then \(W_1=1-\tfrac{1-a_P^2}{1+a_P^2}=2s_P\) exactly, and \(s_P=\sin^2(\theta_P/2)\) for \(U_P=e^{i\theta_P}\). Also \(c_k\) acts on it by the spread polynomial: \(s_P^{(k)}=S_k(s_P)\). The weak-field limit \(W_1\approx\tfrac12e^2\Phi^2\) still requires \(a_P\approx-\tfrac12e\Phi\), i.e. the continuum limit. So “exact” here means \(W_1\) and \(s_P\) are the same function, not that the Maxwell action is obtained without a limit.

Not established. That \(s_P\) is the Gram-determinant solid spread of a tripod built from the plaquette. For that one needs a map from an abelian plaquette (a single phase) to three rays in a projective plane, with \(\det G_3/\prod Q=\sin^2(\theta_P/2)\). No such map was constructed. Two cautions from direct checks:

  • Field membership. An arbitrary rational \(\mathcal S\) is the spread of a rational phase only when \(\mathcal S/(1-\mathcal S)\) is a square. The tripod \(v_1=(1,0,0)\), \(v_2=(1,1,0)\), \(v_3=(1,1,1)\) in \(\mathbb Q^3\) has \(\mathcal S=1/6\), hence \(a_P^2=1/5\), which is not a rational square, and over \(\mathbb F_7\) it gives \(a_P^2=3\), a nonsquare. Its arithmetic is consistent, but it does not correspond to a rational \(\mathrm U(1)\) plaquette phase.
  • Geometric holonomy. The honest holonomy of the Levi-Civita connection around the octant triangle of an orthogonal tripod has half-trace \(\cos(\Omega/2)=\cos(\pi/4)\) (solid angle \(\Omega=\pi/2\)), not \(-1\). So \(w=1-2\mathcal S\) is not the parallel-transport holonomy of a spherical triangle; if it holds, it holds for a different, still-to-be-defined construction.

The “spin lift” reading. For a charge-1 field in the \(\mathrm U(1)\subset\mathrm{SL}(2)\) embedding \(\mathrm{diag}(U,\bar U)\), the vector (adjoint) representation is charge 2. So “a vector sees \(U_P=-1\) as trivial while a spinor does not” is exactly “charge 2 sees \(U_P^2=1\) while charge 1 sees \(-1\).” The quantity that vanishes there is \(S_2(s)=4s(1-s)\), the spread seen by charge 2. But both \(W_1\) and \(W_2=(1-w)^2\) are nonzero at \(w=-1\), so the quartic potential has no special claim to “detect the \(\mathbb Z_2\).” Part 1 already noted that \(W_2\approx\theta^4/4\) does not reproduce Maxwell, so \(W_1\) should be used for electromagnetism.

I have deferred a tripod calculation until the missing map is available; the tripod arithmetic itself is routine.

Where the connection stops

  • No matter field, no action. Calculations 11 and 12 give the covariant difference and charge on the lattice, but not a Dirac operator, a fermion action, or the coupling of \(\psi\) to the Cayley dynamics of Calculation 10.
  • Lattice, not Lorentz-covariant. The identity is exact, but the lattice is hypercubic with a Euclidean \(\varepsilon\); the Hodge star and Lorentz covariance remain the open problem from Part 1.
  • Finite-field limits. Over \(\mathbb F_p\) there is no ordering, so no weak field and no continuum limit. Only the exact identities and the \(\mathbb Z_{p+1}\) structure survive, plus whatever real model one builds on top by choosing a generator (see the warning above).
  • Non-abelian is only a hinge. The commutator identity holds for \(\mathrm{SL}(2)\) caps, but no non-abelian dynamics, Wilson loops or phase analysis were done.

Next directions

  1. Matter field. A Wilson-type hopping term \(\bar\psi_x\gamma^\mu U_\mu(x)\psi_{x+\hat\mu}\) over \(K\), which is gauge invariant by Calculation 11’s covariance, with the fermion-doubling issue to be handled.
  2. Dynamics from a spacetime action. Restore the time links so the Gauss law of Calculation 10 becomes a consequence of gauge invariance rather than of the chosen gauge.
  3. Mass term. Show directly that \(a\mapsto a\oplus b\) does not preserve a \(\sum a^2\) term, the lattice version of the lecture’s \(m_A=0\) argument.
  4. Tripod map. Either construct a map from a plaquette to a tripod with \(\det G_3/\prod Q=\sin^2(\theta_P/2)\), or drop the claim.

Reproducing Calculations 11 and 12

The full script reproduces every table above (it uses numpy and scipy only for the floating-point parts, 11(e) and the \(\mathbb Z_N\) comparison).

"""
Reproduction script for Calculations 11 and 12 (Part 2).

  11. Lattice covariant difference  D_mu psi(x) = U_mu(x) psi(x+mu) - psi(x)  with Cayley link phases
      (a) [D_mu, D_nu] psi = (U_P - 1) T psi           exact identity, for any links and any psi
      (b) gauge covariance of D and of [D, D]; gauge invariance of U_P
      (c) Cayley form of the field strength:  a_P = i [D_mu, D_nu] psi / S psi   and   U_P - 1 = -2 i a_P/(1 + i a_P)
      (d) the same identity for non-abelian SL(2,Q) caps (the Yang-Mills hinge)
      (e) continuum limit in floating point: [D_mu, D_nu] psi -> i q eps^2 F_{mu nu} psi, with D = d + i q A
  12. Charge q:  U -> U^q is the Cayley map c_q(a) = tan(q arctan a) (the tangent multiple-angle map)
      (a) closed forms, Chebyshev relation Re U^q = T_q(Re U)
      (b) homomorphism, additivity in q, periodicity in q mod (p+1), exhaustive over F_p
      (c) the phase group over F_p is cyclic of order N = p+1 (a Z_N gauge theory)
      (d) charge-q covariant derivative and plaquette over Q, F_7, F_11
      (e) single-plaquette comparison Z_N versus U(1)

Needs: numpy, scipy (parts 11e and 12e only).  Runs in well under a minute.
"""
import itertools
import math
import random
from fractions import Fraction as Fr

# ------------------------------------------------------------------ fields ---
class Fp:
    p = 7
    def __init__(s, v): s.v = int(v) % Fp.p
    def __add__(s, o): return Fp(s.v + _v(o))
    __radd__ = __add__
    def __sub__(s, o): return Fp(s.v - _v(o))
    def __rsub__(s, o): return Fp(_v(o) - s.v)
    def __neg__(s): return Fp(-s.v)
    def __mul__(s, o): return Fp(s.v * _v(o))
    __rmul__ = __mul__
    def __truediv__(s, o): return Fp(s.v * pow(_v(o), -1, Fp.p))
    def __rtruediv__(s, o): return Fp(_v(o) * pow(s.v, -1, Fp.p))
    def __eq__(s, o): return s.v == _v(o) % Fp.p
    def __hash__(s): return hash(s.v)
    def __repr__(s): return str(s.v)

def _v(o): return o.v if isinstance(o, Fp) else int(o)

# ------------------------------------------- K = F[i] as pairs (re, im) -------
def kadd(u, v): return (u[0] + v[0], u[1] + v[1])
def ksub(u, v): return (u[0] - v[0], u[1] - v[1])
def kmul(u, v): return (u[0] * v[0] - u[1] * v[1], u[0] * v[1] + u[1] * v[0])
def kconj(u): return (u[0], -u[1])
def kinv(u):
    n = u[0] * u[0] + u[1] * u[1]
    return (u[0] / n, -u[1] / n)
def kpow(u, q, one, zero):
    if q < 0: return kpow(kinv(u), -q, one, zero)
    r = (one, zero)
    for _ in range(q): r = kmul(r, u)
    return r
def ki(u): return (-u[1], u[0])                       # multiplication by i

class Ring:
    """Bundles the base field F: constructor mk, constants, Cayley phase and its inverse."""
    def __init__(s, mk): s.mk, s.one, s.zero = mk, mk(1), mk(0)
    def phase(s, a):                                   # U = (1 - i a)/(1 + i a);  a = None means infinity
        o, z = s.one, s.zero
        if a is None: return (-o, z)
        d = o + a * a
        return ((o - a * a) / d, s.mk(-2) * a / d)
    def a_of(s, u):                                    # inverse Cayley map
        return None if u[0] == -s.one else -u[1] / (s.one + u[0])
    def oplus(s, a, b): return s.a_of(kmul(s.phase(a), s.phase(b)))      # tangent addition
    def cq(s, a, q): return s.a_of(kpow(s.phase(a), q, s.one, s.zero))   # Cayley charge map

RQ = Ring(Fr)
def RF(p):
    Fp.p = p
    return Ring(Fp)

# --------------------------------------------------------------- lattice ----
D4, L4 = 4, 3
SITES = list(itertools.product(range(L4), repeat=D4))
def sh(x, m): return tuple((x[i] + (i == m)) % L4 for i in range(D4))
PAIRS = [(m, n) for m in range(D4) for n in range(m + 1, D4)]

def Dop(U, m, f):                                      # (D_m f)(x) = U_m(x) f(x+m) - f(x)
    return {x: ksub(kmul(U[(x, m)], f[sh(x, m)]), f[x]) for x in SITES}

def plaq(U, x, m, n):                                  # U_m(x) U_n(x+m) U_m(x+n)^-1 U_n(x)^-1
    return kmul(kmul(U[(x, m)], U[(sh(x, m), n)]), kmul(kconj(U[(sh(x, n), m)]), kconj(U[(x, n)])))

def transport(U, f, x, m, n):                          # T f(x) = U_n(x) U_m(x+n) f(x+m+n)
    return kmul(kmul(U[(x, n)], U[(sh(x, n), m)]), f[sh(sh(x, m), n)])

def twopath(U, f, x, m, n):                            # S f(x) = (U_m U_n' + U_n U_m') f(x+m+n)
    t = f[sh(sh(x, m), n)]
    return kmul(kadd(kmul(U[(x, m)], U[(sh(x, m), n)]), kmul(U[(x, n)], U[(sh(x, n), m)])), t)

def random_links(R, rand, rng):
    return {(x, m): R.phase(rand(rng)) for x in SITES for m in range(D4)}

def random_psi(R, rand, rng):
    out = {}
    for x in SITES:
        while True:
            v = (rand(rng, False), rand(rng, False))
            if v != (R.zero, R.zero) and not (v[0] == R.zero and v[1] == R.zero): break
        out[x] = v
    return out

def checks(R, rand, q=1, seed=11):
    rng = random.Random(seed)
    U1 = random_links(R, rand, rng)
    U = {k: kpow(u, q, R.one, R.zero) for k, u in U1.items()} if q != 1 else U1       # charge-q links
    psi = random_psi(R, rand, rng)
    n = dict(ident=0, cayley=0, ratio=0, covD=0, covC=0, inv=0, qmap=0)
    tot = dict(ident=0, cayley=0, ratio=0, covD=0, covC=0, inv=0, qmap=0)
    g = {x: R.phase(rand(rng)) for x in SITES}                        # gauge transformation (charge-1 phase)
    gq = {x: kpow(g[x], q, R.one, R.zero) for x in SITES}
    Up = {(x, m): kmul(kmul(gq[x], U[(x, m)]), kconj(gq[sh(x, m)])) for x in SITES for m in range(D4)}
    psip = {x: kmul(gq[x], psi[x]) for x in SITES}
    Dn = {m: Dop(U, m, psi) for m in range(D4)}
    Dnp = {m: Dop(Up, m, psip) for m in range(D4)}
    for m in range(D4):                                               # covariance of D
        for x in SITES:
            tot["covD"] += 1; n["covD"] += Dnp[m][x] == kmul(gq[x], Dn[m][x])
    for (m, nn) in PAIRS:
        Cm = {x: ksub(Dop(U, m, Dn[nn])[x], Dop(U, nn, Dn[m])[x]) for x in SITES}
        Cp = {x: ksub(Dop(Up, m, Dnp[nn])[x], Dop(Up, nn, Dnp[m])[x]) for x in SITES}
        for x in SITES:
            P = plaq(U, x, m, nn)
            T = transport(U, psi, x, m, nn)
            tot["ident"] += 1; n["ident"] += Cm[x] == kmul(ksub(P, (R.one, R.zero)), T)          # [D,D] psi = (U_P - 1) T psi
            tot["covC"] += 1; n["covC"] += Cp[x] == kmul(gq[x], Cm[x])                          # covariance of the commutator
            tot["inv"] += 1; n["inv"] += plaq(Up, x, m, nn) == P                                # gauge invariance of U_P
            a = R.a_of(P)
            S = twopath(U, psi, x, m, nn)
            tot["ratio"] += 1
            if a is None: n["ratio"] += S == (R.zero, R.zero)                                   # U_P = -1: S psi = 0
            else: n["ratio"] += ki(kmul(Cm[x], kinv(S))) == (a, R.zero)                         # a_P = i [D,D]psi / S psi
            tot["cayley"] += 1
            if a is None: n["cayley"] += P == (-R.one, R.zero)
            else: n["cayley"] += kmul(ksub(P, (R.one, R.zero)), (R.one, a)) == (R.zero, R.mk(-2) * a)   # (U_P - 1)(1 + i a_P) = -2 i a_P
            tot["qmap"] += 1
            a1 = R.a_of(plaq(U1, x, m, nn))
            if q == 1: n["qmap"] += 1
            else: n["qmap"] += (R.cq(a1, q) == a)                                               # a_P^(q) = c_q(a_P)
    return n, tot

# ---------------------------------------------- 11d: non-abelian SL(2,Q) -----
def m2(a, b, c, d): return ((a, b), (c, d))
def mmul(A, B): return tuple(tuple(sum(A[i][k] * B[k][j] for k in range(2)) for j in range(2)) for i in range(2))
def msub(A, B): return tuple(tuple(A[i][j] - B[i][j] for j in range(2)) for i in range(2))
def madd(A, B): return tuple(tuple(A[i][j] + B[i][j] for j in range(2)) for i in range(2))
def mdet(A): return A[0][0] * A[1][1] - A[0][1] * A[1][0]
def minv(A):
    d = mdet(A)
    return ((A[1][1] / d, -A[0][1] / d), (-A[1][0] / d, A[0][0] / d))
def mvec(A, v): return tuple(sum(A[i][j] * v[j] for j in range(2)) for i in range(2))
def vsub(u, v): return tuple(a - b for a, b in zip(u, v))
I2 = ((Fr(1), Fr(0)), (Fr(0), Fr(1)))

def cap(A): return mmul(madd(I2, A), minv(msub(I2, A)))               # Cayley cap (I + A)(I - A)^-1

def nonabelian_check(seed=5):
    rng = random.Random(seed)
    def rA():
        while True:
            a, b, c = (Fr(rng.randint(-3, 3), rng.randint(1, 3)) for _ in range(3))
            A = ((a, b), (c, -a))
            if mdet(msub(I2, A)) != 0: return A
    U = {(x, m): cap(rA()) for x in SITES for m in range(D4)}
    psi = {x: (Fr(rng.randint(-5, 5)), Fr(rng.randint(-5, 5))) for x in SITES}
    Dm = lambda m, f: {x: vsub(mvec(U[(x, m)], f[sh(x, m)]), f[x]) for x in SITES}
    ok = tot = 0; nonabelian = 0
    for (m, n) in PAIRS:
        C = {x: vsub(Dm(m, Dm(n, psi))[x], Dm(n, Dm(m, psi))[x]) for x in SITES}
        for x in SITES:
            P = mmul(mmul(U[(x, m)], U[(sh(x, m), n)]), mmul(minv(U[(sh(x, n), m)]), minv(U[(x, n)])))
            T = mvec(mmul(U[(x, n)], U[(sh(x, n), m)]), psi[sh(sh(x, m), n)])
            ok += C[x] == mvec(msub(P, I2), T); tot += 1
            Q = mmul(mmul(U[(x, n)], U[(sh(x, n), m)]), mmul(U[(x, m)], U[(sh(x, m), n)]))      # reversed loop product
            nonabelian += mmul(U[(x, m)], U[(sh(x, m), n)]) != mmul(U[(x, n)], U[(sh(x, n), m)])
    return ok, tot, nonabelian

# --------------------------------- 11e: continuum limit in floating point ----
def continuum_limit(q=1.3):
    import cmath
    x0, y0 = 0.1, 0.2
    Ax = lambda x, y: 0.3 * math.sin(2 * math.pi * y) + 0.1 * x
    Ay = lambda x, y: 0.2 * math.cos(2 * math.pi * x) + 0.15 * y
    F = lambda x, y: -0.4 * math.pi * math.sin(2 * math.pi * x) - 0.6 * math.pi * math.cos(2 * math.pi * y)   # d_x A_y - d_y A_x
    psi = lambda x, y: cmath.exp(1j * (0.7 * x + 0.4 * y)) * (1 + 0.3 * x - 0.2 * y)
    out = []
    for k in (3, 4, 5, 6, 7):
        e = 2.0 ** -k
        Ux = lambda x, y: cmath.exp(1j * q * (0.3 * math.sin(2 * math.pi * y) * e + 0.05 * ((x + e) ** 2 - x ** 2)))
        Uy = lambda x, y: cmath.exp(1j * q * (0.2 * math.cos(2 * math.pi * x) * e + 0.075 * ((y + e) ** 2 - y ** 2)))
        Dx = lambda f: (lambda x, y: Ux(x, y) * f(x + e, y) - f(x, y))
        Dy = lambda f: (lambda x, y: Uy(x, y) * f(x, y + e) - f(x, y))
        C = Dx(Dy(psi))(x0, y0) - Dy(Dx(psi))(x0, y0)
        R = C / (1j * q * e * e * F(x0, y0) * psi(x0, y0))
        out.append((e, R))
    return out

# ----------------------------------------------------------- charge map -----
def cheb(q, x):                                        # Chebyshev T_q(x), exact on Fractions or Fp
    t0, t1 = x * 0 + 1, x
    if q == 0: return t0
    for _ in range(q - 1): t0, t1 = t1, 2 * x * t1 - t0
    return t1

def charge_checks():
    rng = random.Random(9)
    res = {}
    # closed forms over Q
    ok2 = ok3 = okim = okT = tot = 0
    for _ in range(300):
        a = Fr(rng.randint(-20, 20), rng.randint(1, 9))
        if 1 - a * a != 0 and 1 - 3 * a * a != 0:
            tot += 1
            ok2 += RQ.cq(a, 2) == 2 * a / (1 - a * a)
            ok3 += RQ.cq(a, 3) == (3 * a - a ** 3) / (1 - 3 * a * a)
        z = kpow((Fr(1), a), 5, Fr(1), Fr(0))                              # (1 + i a)^5
        okim += (RQ.cq(a, 5) == (z[1] / z[0] if z[0] != 0 else None))
        for q in range(1, 7):
            u = kpow(RQ.phase(a), q, Fr(1), Fr(0))
            okT += u[0] == cheb(q, (1 - a * a) / (1 + a * a))
    res["closed"] = (ok2, ok3, tot, okim, 300, okT, 300 * 6)
    # homomorphism over Q (random) and over F_p (exhaustive)
    h = hq = 0
    for _ in range(500):
        a, b = (None if rng.random() < 0.05 else Fr(rng.randint(-9, 9), rng.randint(1, 5)) for _ in range(2))
        for q in (2, 3, 4, 5, -1, -3):
            hq += 1; h += RQ.cq(RQ.oplus(a, b), q) == RQ.oplus(RQ.cq(a, q), RQ.cq(b, q))
    res["hom_Q"] = (h, hq)
    rows = []
    for p in (3, 7, 11, 19, 23):
        R = RF(p); N = p + 1
        pts = [None] + [Fp(v) for v in range(p)]
        hom = add = per = comp = tt = 0
        for a in pts:
            for b in pts:
                for q in (2, 3, 5):
                    tt += 1; hom += R.cq(R.oplus(a, b), q) == R.oplus(R.cq(a, q), R.cq(b, q))
            for q in range(0, N + 2):
                for r in (1, 2, 3, 5):
                    add += R.cq(a, q + r) == R.oplus(R.cq(a, q), R.cq(a, r))
                    comp += R.cq(R.cq(a, r), q) == R.cq(a, q * r)
                per += R.cq(a, q + N) == R.cq(a, q)
        # group order and generator
        zero = Fp(0)
        def order(a):
            k, b = 1, a
            while not (b is not None and b == zero): b = R.oplus(b, a); k += 1
            return k
        orders = [order(a) for a in pts]
        gens = [a for a, o in zip(pts, orders) if o == N]
        ncharge = len(pts)
        rows.append((p, N, ncharge, max(orders), len(gens), hom, tt, add, per, comp,
                     len(pts) * (N + 2) * 4, len(pts) * (N + 2)))
    res["Fp"] = rows
    return res

def tableau_generator(p):
    R = RF(p); N = p + 1
    pts = [None] + [Fp(v) for v in range(p)]
    zero = Fp(0)
    for a in pts:
        b, k = a, 1
        while not (b is not None and b == zero): b = R.oplus(b, a); k += 1
        if k == N:
            return [R.cq(a, q) for q in range(N)]

def zn_vs_u1(beta):
    import numpy as np
    from scipy.special import iv
    u1 = iv(1, beta) / iv(0, beta)
    out = {}
    for N in (4, 8, 12, 20, 24):
        th = 2 * np.pi * np.arange(N) / N
        w = np.exp(beta * np.cos(th))
        out[N] = float((np.cos(th) * w).sum() / w.sum())
    return u1, out
